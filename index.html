Presets

Choosing a preset from the list loads it right away. If your current settings are not saved in any preset, you are asked before they are replaced. A preset stores the message type, items and prices, name, layout, fill, tag styles and other format settings, but not the timer sound or volume. Saving with an existing name replaces it. Presets live in this browser only, so they will not appear on another device or browser, and clearing site data removes them.

Lines

Import reads a message like <<<Selling>>> ITEM <<<100K>>> and turns it back into editable lines. Your browser will ask for clipboard permission.

Format

One item per row measures each piece of text. With ㅡ, _ or @ it fills each item's row to full width with the fill split around the text (ㅡㅡItemㅡㅡ). With Blank it adds just enough spaces after each item that the next item cannot fit on the same row, and adds nothing when the next item would wrap by itself, which saves characters. The game shows your name at the start of the first row, so it counts against that row. Widths are estimates: if rows do not line up in game, change “@ per full row” (decimals work). Fill characters count toward the character limit, and an over-limit message is flagged in red. Blank uses the most characters and ㅡ the fewest.

Template: {item} {price}. {br} starts a new row and {gap} pushes the text after it to the right edge of the row. Tag styles use {type} or {t} (first letter). The tag appears once per message, and the style switches after each copy when that box is checked.
